# Course Title

uPy-1000: MicroPython for Everyone

# Sub-Title

Fast & Efficient Programming on Linux

## Key Topics

MicroPython, MicroPython 1000, uPy 1000, Modern Python, collections, design, requirements,
open source, flowcharts, diagrams, professional, use cases, docstring, function
machine, state machines

## What You Will Learn

🪄Practice the ‘core’ syntax that works
across all Python programming platforms.

🪄Discover the difference between modern
Python and MicroPython.

🪄Learn how to run MicroPython on most Linux
and many POSIX inspired systems.

🪄Discover / review Functional Python
concepts (Python 1000.)

🪄Discover / review Classes and Modules
(Python 2000.)

🪄Discover / review file modes &
Concepts (Python 3000 concept.)

🪄Create / review IPC Communications
(Python 4000 concept.)

🪄Create a Client & Server LED
Emulator.

## Audience
No prior knowledge of Python or programming is required.
This educational opportunity is designed for both new software developers as
well as professionals wanting to review common Python concepts. Topics range
from the new software developer to the advanced.
